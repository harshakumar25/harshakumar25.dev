# Harsh Kumar — Portfolio

Personal portfolio and interactive showcase for **Harsh Kumar**, FullStack Developer & Security Engineer.

Built with [Astro](https://astro.build), [SCSS](https://sass-lang.com/), [Three.js](https://threejs.org/), and [GSAP](https://greensock.com/gsap/).

---

## 🚀 Quick Start

To run the project locally:

```bash
# 1. Clone this repository
git clone https://github.com/harshakumar25/PortfolioWebsite.git
cd PortfolioWebsite

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
```

The site will be available at `http://localhost:4321`.

---

## 🛠️ Architecture & Tech Stack

- **Core Framework**: Astro 5 (Zero-JS static island architecture)
- **Styling**: Vanilla SCSS with fluid responsive grid design tokens
- **3D Graphics & Canvas**: Three.js custom shaders and particle systems
- **Motion & Physics**: GSAP 3 + Lenis smooth scroll
- **Deployment**: Automated CI/CD with GitHub Actions to GitHub Pages
